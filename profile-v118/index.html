Robot Learning for Memory-Guided Manipulation

ReuseMemOne Memory, Multiple Goals in Robot Manipulation

Yoonseok Kang, Dayeon Jung, Seunghoon Jeon, Wonjib Kim, Dongchul Park

arXiv preprint, 2026

Project and demos Read the paper

A robot may see where an object is or what a case contains before it knows what it will be asked to do. ReuseMem learns which observations to retrieve from the same history as new goals arrive.

I trained the retriever with expert-action prediction and built an adapter that combines past observations with the current scene for a frozen vision-language-action policy. I designed controlled comparisons in simulation and evaluated the method on a physical robot arm.
