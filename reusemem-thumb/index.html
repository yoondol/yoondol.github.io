Papers

  1. 1

    ReuseMem: One Memory, Multiple Goals in Robot Manipulation

    Yoonseok Kang, Dayeon Jung, Seunghoon Jeon, Wonjib Kim, Dongchul Park

    arXiv preprint, 2026.

    I built ReuseMem to test whether a robot can use one recording for different requests given later. I trained a goal-conditioned retriever to select sets of observations that help predict expert actions, and built a learned adapter that combines them with the current scene for a frozen policy. In simulation, I compared learned retrieval against evenly spaced frames at the same memory budget. I also tested it on a physical SO-101 arm.
