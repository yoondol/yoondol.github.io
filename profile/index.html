Robot Learning for Memory-Guided Manipulation

ReuseMem: One Memory, Multiple Goals in Robot Manipulation

Yoonseok Kang, Dayeon Jung, Seunghoon Jeon, Wonjib Kim, Dongchul Park

arXiv preprint, 2026

Project page arXiv PDF

Problem

A robot may see where an object is or what a case contains before it knows what it will be asked to do. In the real-robot task, it observes two cases before they are moved. From the same recording, it later needs to retrieve the case holding a USB drive and then return it to its original location. ReuseMem learns which observations to retrieve from the same history as new goals arrive.

Approach

I trained a goal-conditioned retriever with expert-action prediction and built an adapter that combines the selected observations with the current scene for a frozen vision-language-action policy. In simulation, I compared retrieval with evenly spaced frames at the same memory budget, and I evaluated the method on an SO-101 arm.
